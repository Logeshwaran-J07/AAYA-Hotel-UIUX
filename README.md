
## About the Project
AAYA Hotel is a mobile food ordering application designed for small local hotels.

## Problem Statement
Customers spend too much time waiting for food orders and face difficulties finding available seating.

## Our Solution
- Pre-order food online.
- View food prices and preparation time.
- Check hotel seating availability.
- Get pickup notifications.
- Smart arrival and order tracking.

## Key Features
- Food menu
- Checkout and order review
- Smart arrival tracking
- Customer profile
- Pickup management

## Tools Used
- Figma
- UI/UX Design

## Project Screens
This repository contains the UI screens of the AAYA Hotel application.

## Project Goal
To reduce customer waiting time and improve the food pickup experience at small local hotels.
